# ChallengeCalculator-in-C-using-only-Operator
A calculator in C language which has a challenge, it can only use + for all operations of +,-,*,/. 

1. This Project I completed in 16 days time. (Not including 2 days before submission as that was for making 
code readable and better with gaps and easy comments) , From learning basics from w3school website to building 
this calculator

2. Compiler used - Embarcadero Dev-C++ (Original Dev-C++ kept crashing so uninstalled & reinstalled this)

3. Editor - For writing from scratch I used Notepad.

I Used the TDM-GCC 64Bit Debug Compiler option in the Dev-C++ app , this gave .exe file and made easy to run 
the program instead of launching through main.c 

CREDITS - w3schools , Embarcadero Dev-C++
